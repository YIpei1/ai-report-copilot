# 报表模块业务原型文档

## 1. 文档目标

本文档描述报表模块的页面结构、业务流程、交互规则和状态变化，用于指导后续代码重构、功能测试和 AI 会话接入。

本文档只描述产品原型，不包含视觉设计图。

## 2. 业务目标

报表模块用于完成以下闭环：

```text
维护基础数据
→ 创建检测模板
→ 配置报告组件
→ 选择设备和工具箱创建检测
→ 填写检测报告
→ 保存草稿或待审核报告
→ 在报告管理中继续编辑
```

未来 AI 会话与手动创建共用同一套报告数据和校验规则。

## 3. 页面信息架构

### 3.1 后台菜单

```text
报表模块
├─ 报告管理
└─ 检测模板

基础数据
├─ 设备台账
├─ 仪器设备
└─ 工具箱
```

### 3.2 页面路由

| 页面     | 路由                                           | 说明                 |
| -------- | ---------------------------------------------- | -------------------- |
| 报告管理 | `/reports/manage`                              | 查询和编辑已保存报告 |
| 检测模板 | `/reports/templates`                           | 管理模板并创建检测   |
| 创建报告 | `/reportView/:templateId/:deviceId/:toolboxId` | 首次生成报告         |
| 编辑报告 | `/reportView/edit/:reportId`                   | 编辑已保存报告快照   |

## 4. 核心业务对象

### 4.1 检测模板

检测模板定义报告由哪些页面组件组成，以及这些组件的排列顺序。

检测模板不绑定具体设备，也不固定工具箱。

### 4.2 设备台账

设备台账保存被检测电梯的身份信息和技术参数，用于生成首页和自行检测记录中的初始字段。

### 4.3 仪器设备

仪器设备保存检测工具的名称、编号、型号、用途、检定有效期和使用状态。

### 4.4 工具箱

工具箱是一组仪器设备的组合。创建检测时选择工具箱，用于生成“主要检测仪器设备”模块。

### 4.5 检测报告

检测报告是一份可以独立保存和重新编辑的业务实例，包含：

- 报告列表摘要。
- 报告填写数据。
- 模板快照。
- 设备快照。
- 工具箱快照。
- 仪器快照。
- 校验结果。

## 5. 检测模板页面

### 5.1 页面目标

用于查询、创建、删除检测模板，配置模板包含的报告组件，并从模板发起一次检测。

### 5.2 页面结构

页面从上到下分为：

1. 页面标题和“新增模板”按钮。
2. 搜索区域。
3. 模板数据表格。
4. 分页区域。

### 5.3 搜索区域

搜索字段：

- 关键词：匹配模板名称或编号。
- 版本：匹配模板版本。

操作：

- 查询：从第一页重新加载模板列表。
- 重置：清空搜索条件并重新加载列表。

### 5.4 模板表格

建议展示：

- 模板名称。
- 模板编号。
- 版本。
- 已配置组件数量。
- 更新时间。
- 操作。

操作包括：

- 配置组件。
- 创建检测。
- 删除。

## 6. 新增检测模板

### 6.1 打开方式

点击检测模板页面右上角“新增模板”。

### 6.2 表单字段

| 字段     | 必填 | 说明               |
| -------- | ---- | ------------------ |
| 模板名称 | 是   | 模板业务名称       |
| 模板编号 | 是   | 模板唯一业务编号   |
| 模板版本 | 是   | 默认可以使用 `1.0` |
| 模板说明 | 否   | 模板适用场景说明   |

### 6.3 提交结果

点击“创建并配置组件”后：

1. 校验必填字段。
2. 创建模板基础信息。
3. 刷新模板列表。
4. 自动打开该模板的组件配置弹窗。

## 7. 配置报表组件

### 7.1 页面目标

决定当前检测模板包含哪些报告页面以及最终页面顺序。

### 7.2 可配置组件

当前支持：

1. 首页。
2. 电梯自行检测记录。
3. 检测条件及主要检测仪器设备。
4. 检测项目、内容和要求。

### 7.3 交互规则

- 首页固定选中。
- 首页固定在报告第一项。
- 首页不能取消，也不能拖拽。
- 其他组件可以勾选或取消。
- 其他组件直接拖拽组件卡片调整顺序。
- 不额外提供独立拖拽图标。
- 点击组件仍然执行勾选或取消，发生拖拽时不触发勾选行为。

### 7.4 保存结果

点击“保存配置”后保存：

- 组件 ID。
- 组件标题。
- 组件顺序。

模板本身不保存设备、工具箱和报告填写数据。

## 8. 创建检测

### 8.1 打开方式

在模板列表点击“创建检测”。

### 8.2 弹窗内容

需要选择：

- 检测设备。
- 检测工具箱。

### 8.3 设备规则

- 只展示设备台账中状态为启用的设备。
- 设备停用后不能用于创建新的检测。
- 已保存报告中的历史设备快照不受停用影响。

### 8.4 工具箱规则

工具箱满足以下条件时才可以选择：

- 工具箱自身启用。
- 已配置仪器设备。
- 关联仪器没有被删除。
- 关联仪器没有停用。
- 关联仪器没有过期。
- 关联仪器检定有效期正常。

### 8.5 确认结果

选择完成后进入报告编辑器，并携带：

```text
templateId
deviceId
toolboxId
```

## 9. 报告编辑器

### 9.1 页面布局

页面分为：

```text
顶部操作区
├─ 返回
├─ 当前模板或报告名称
└─ 保存

主体区域
├─ 左侧报告目录
├─ 中间报告页面
└─ 右侧问题提示
```

### 9.2 首次创建数据来源

首次进入报告编辑器时：

1. 根据 `templateId` 查询模板和组件顺序。
2. 根据 `deviceId` 查询设备完整信息。
3. 根据 `toolboxId` 查询工具箱及其仪器。
4. 生成本次报告的基础数据快照。
5. 将数据转换成报告文档树。

### 9.3 自动带入内容

首页自动带入：

- 报告名称。
- 使用单位。
- 设备名称。
- 当前检测日期。

自行检测记录自动带入：

- 使用单位。
- 安装地点。
- 设备编号。
- 注册代码。
- 设备类别。
- 产品型号。
- 制造单位。
- 维保单位。
- 额定载重量。
- 额定速度。
- 层、站、门数量。
- 当前检测日期。
- 默认检测依据。

检测条件及主要检测仪器设备自动带入：

- 检测地点。
- 工具箱中的仪器名称。
- 仪器编号。
- 仪器状态。

检测项目模块自动带入：

- 检测项目序号。
- 项目编号。
- 检测项目名称。
- 内容和要求。

用户负责填写检测结果等现场数据。

## 10. 报告填写规则

### 10.1 主要检测仪器设备

仪器状态使用标准业务用语：

```text
可用
不可用
```

判断规则：

- `可用`：正常。
- `不可用`：异常，报告保存为草稿。
- 空值：未填写，报告保存为草稿。
- 其他内容：输入不规范，报告保存为草稿。

### 10.2 检测项目

检测结果用于记录现场检测数据、现象或者说明：

- 允许输入自由文本。
- 允许填写数值、描述或者“不适用”等现场结果。
- 检测结果不能为空。
- 检测结果不直接决定项目是否符合。

单项结论使用标准业务用语：

```text
符合
不符合
```

判断规则：

- `符合`：正常。
- `不符合`：不符合项，报告保存为草稿。
- 空值：单项结论未填写，报告保存为草稿。
- 其他内容：单项结论输入不规范，报告保存为草稿。

### 10.3 备注

- 备注允许为空。
- 备注允许输入自由文本。
- 备注不参与完整性和合格状态判断。

### 10.4 AI 输入规范

未来 AI 需要将用户自然语言整理为标准业务值：

```text
“这个项目没有问题” → 单项结论“符合”
“这个仪器可以正常使用” → “可用”
```

AI 和手动填写必须使用同一套校验规则。

## 11. 保存报告

### 11.1 保存前处理

点击保存后：

1. 整理报告页面顺序。
2. 检查必填字段。
3. 检查未检测项目。
4. 检查不符合项目。
5. 检查不可用仪器。
6. 检查非标准业务输入。
7. 生成报告快照数据。

### 11.2 保存为草稿

出现任意问题时：

- 状态设置为 `draft`。
- 保存报告和全部快照。
- 弹窗提示问题数量。
- 用户可以继续填写。
- 首次保存后路由切换为报告编辑路由，刷新页面仍可恢复数据。

提示内容按问题类型组合：

```text
未填写项数量
不合格项数量
不可用仪器数量
输入不规范项数量
```

### 11.3 正常保存

全部填写且业务判断正常时：

- 状态设置为 `pending_review`。
- 保存报告和全部快照。
- 提示保存成功。
- 返回报告管理页面。

当前 `pending_review` 表示待审核，审核动作尚未开发。

## 12. 报告管理

### 12.1 页面目标

集中查询由手动流程或 AI 流程生成的报告。

### 12.2 搜索字段

- 关键词：报告名称、编号或设备名称。
- 创建方式：手动创建、AI 创建。
- 报告状态。
- 创建人员。
- 创建时间范围。
- 检测模板。

### 12.3 表格字段

- 报告编号。
- 报告名称。
- 检测设备。
- 使用单位。
- 检测模板。
- 创建方式。
- 报告状态。
- 创建人员。
- 创建时间。
- 操作。

### 12.4 编辑报告

点击“编辑”后：

1. 携带 `reportId` 进入报告编辑器。
2. 只请求报告详情。
3. 读取已保存的模板、设备、工具箱和仪器快照。
4. 读取已保存的报告文档数据。
5. 不再请求当前基础数据。

即使之后设备停用、工具箱调整或者仪器过期，也不能改变历史报告内容。

## 13. 报告状态流程

当前和规划中的状态变化：

```text
填写存在问题
→ 草稿
→ 修改并重新保存

填写完整且正常
→ 待审核
→ 已通过
或
→ 已驳回
→ 修改后重新提交
```

当前已经实现：

- 草稿。
- 待审核。
- 草稿重新编辑。
- 待审核报告重新编辑。

当前尚未实现：

- 提交审核按钮。
- 审核操作。
- 驳回原因。
- 审核记录。
- 报告删除。
- 报告导出和打印。

## 14. AI 会话接入预留

AI 会话不直接操作页面 DOM，而是修改与手动填写相同的报告文档数据。

建议流程：

```text
选择或创建报告任务
→ AI 找到下一个未填写字段
→ 向用户提出问题
→ 识别用户回答对应的字段
→ 转换成标准业务值
→ 写入报告文档数据
→ 重新执行统一校验
→ 用户预览报告
→ 保存到报告管理
```

用户允许跳过 AI 当前提出的问题，直接回答其他检测项目。AI 应先根据项目编号或字段名称定位目标字段，再保存回答，并继续追问原来的未完成项。

## 15. 重构验收清单

报表模块重构后必须保证：

- 模板列表搜索和分页正常。
- 模板新增、删除正常。
- 首页固定且不能取消。
- 组件勾选和拖拽排序正常。
- 设备和工具箱可正常选择。
- 不可用工具箱不会出现在创建检测选项中。
- 报告组件按照模板顺序生成。
- 设备和仪器数据正确带入。
- 检测日期自动带入创建当天。
- 未填写、不符合、不可用和非标准输入判断正确。
- 草稿能够保存并重新打开。
- 重新打开报告不请求当前基础数据。
- 完整报告能够保存并返回报告管理。
- 搜索、分页和状态显示正常。
- `pnpm verify` 全部通过。
